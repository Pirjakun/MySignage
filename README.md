# MySignage V3

Routes:
- `/` = Home
- `/admin` = Admin
- `/tv/landscape` = TV Landscape
- `/tv/portrait` = TV Portrait

Fitur:
- Home page dengan Admin / Landscape / Portrait
- Playlist foto
- Tambah foto berdasarkan URL
- Atur durasi tiap foto
- Naik/turun urutan
- Hapus foto
- Auto loop

Catatan: versi ini memakai localStorage, jadi playlist belum tersinkron antar perangkat. Untuk 4 TV yang dikontrol dari satu Admin, tahap berikutnya perlu backend/storage bersama + WebSocket.
